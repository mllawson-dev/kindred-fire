      Self-initiated concept · Creative Engineering

      An identity that responds like an instrument.

      Kindred Fire extends the Evergrace Music universe into an immersive artist launch experience built around sound, motion, and an ember-led visual system.

      The brief

      Make a fictional release feel alive without relying on a music video or licensed track.

      The experience uses a synthesized audio source so the interaction can be demonstrated without borrowed music. Frequency data shapes every canvas frame, turning the interface into part of the band’s identity.

      Designed

      Artist identity extension, album presentation, interaction flow, responsive UI, and the ember-to-flame motion language.

      Built

      • Web Audio API with synthetic tone and filtered noise
      • Canvas 2D animation driven by live frequency data
      • Vanilla JavaScript tabs, dialog, and state transitions
      • Reduced-motion behavior and browser fallbacks
      Concept disclosure

      The Kindred Fire, Kindled, the lyrics, venues, release date, and tour are fictional content created for this portfolio project.
