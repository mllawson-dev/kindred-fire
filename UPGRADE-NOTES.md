# Kindred Fire portfolio upgrade

## Positioning

Recommended portfolio category: **Creative Engineering**

Recommended project label: **Audio-Reactive Music Experience**

Kindred Fire is a self-initiated concept inside the Evergrace Music universe.
The band, album, release date, lyrics, venues, and tour are fictional content
created to demonstrate the experience.

## What makes the piece strong

- A synthesized Web Audio source avoids borrowed music and licensing concerns.
- Live frequency data drives the Canvas 2D flame system frame by frame.
- The site uses vanilla HTML, CSS, and JavaScript to demonstrate technical range.
- View Transitions and scroll-driven animation include browser fallbacks.
- Native dialog and reduced-motion behavior support accessible interaction.
- The visual system clearly inherits Evergrace gold and charcoal while making
  ember red dominant for the artist identity.
